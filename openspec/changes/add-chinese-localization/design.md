# Design

## Context

当前 UI 文本主要由 WinForms Designer 和 `.resx` 提供，运行时提示散落在客户端、服务器和内置 Lua 脚本中。项目没有现成多语言资源切换机制。

## Goals / Non-Goals

**Goals:**

- 先提供固定简体中文版本。
- 只修改面向用户的自然语言文本。
- 保留协议、命令、地图名和 API 标识。

**Non-Goals:**

- 不实现运行时语言切换。
- 不重构所有字符串为资源键。
- 不翻译调试日志、Lua API 文档或第三方插件文本。

## Decisions

- 直接修改现有 Designer/resx 和内置脚本字符串，避免引入新的本地化框架。
- C# 编译使用 UTF-8 源文件；Lua 文本仅替换用户可见消息。
- 对命令字符串中的英文命令名保留原文，只翻译其 HUD 文本参数。

## Risks / Trade-offs

- `[固定中文]` → 后续若需要英文/多语言，再将文本迁移到资源文件。
- `[第三方插件仍可能输出英文]` → 本次只覆盖 KCOM 自带 UI、运行时和 Lua 文本。

## Follow-up design: Game language support

- 本阶段扩展原来的“仅文本汉化”范围，解除游戏英文启动限制；不扩展为 UI 语言切换。
- 客户端认证后每 2 秒通过 VConsole 调用 `kcom_bootstrap.lua`，附带连接会话标识。脚本等待有效本地玩家，只在新会话或初始化实体缺失时输出固定 `KRDY KCOM`；10 秒节流避免加载中重复初始化。换图重建脚本状态，重连通过新标识重新初始化。禁止匹配各语言的自然语言入场日志。
- 服务端收到完整就绪标记后沿用 INIT/IENT 初始化链，清理旧脚本与计时器，避免重复计时器。仅认证客户端触发。先启用本地 addon 和 Workshop addon，再请求换图。
- VConsole 使用 12 字节报头，偏移 8 的大端 uint16 是总字节长度；PRNT 内容从帧偏移 40 开始。读取满帧后才解码 UTF-8。EOF/截断/非法长度结束读取，不空转；读取任务不占 WinForms 同步上下文。保留 StreamWatcher 旧事件负载布局（从帧偏移 10 起）供现有调用者使用。
- CMND 按 UTF-8 字节数计算长度；超出 uint16 上限或含 NUL 的命令拒绝发送。发送加锁，探测与同步命令不能交错。
- 自动化覆盖真实传输类、Lua 就绪脚本、gamemode 初始化及不同区域数字格式；无头测试不能替代中文游戏内实测，不把“编译通过”写成已验证全语言可玩。

- 初始化握手发生变化，因此桌面协议版本从 0 增加为 1，复用已有版本不匹配提示。所有联机端需更新；游戏脚本 API 4 和 JSON 字段结构不变。
