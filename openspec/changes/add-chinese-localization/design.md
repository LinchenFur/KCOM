# Design

## Context

当前 UI 文本主要由 WinForms Designer 和 `.resx` 提供，运行时提示散落在客户端、服务器和内置 Lua 脚本中。项目没有现成多语言资源切换机制。

## Goals / Non-Goals

**Goals:**

- 先提供固定简体中文版本。
- 只修改面向用户的自然语言文本。
- 保留协议、命令、地图名和 API 标识。

**Non-Goals:**

- 不实现运行时语言切换。
- 不重构所有字符串为资源键。
- 不翻译调试日志、Lua API 文档或第三方插件文本。

## Decisions

- 直接修改现有 Designer/resx 和内置脚本字符串，避免引入新的本地化框架。
- C# 编译使用 UTF-8 源文件；Lua 文本仅替换用户可见消息。
- 对命令字符串中的英文命令名保留原文，只翻译其 HUD 文本参数。

## Risks / Trade-offs

- `[固定中文]` → 后续若需要英文/多语言，再将文本迁移到资源文件。
- `[第三方插件仍可能输出英文]` → 本次只覆盖 KCOM 自带 UI、运行时和 Lua 文本。
