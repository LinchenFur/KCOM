# 修复交互实体与共享资源同步

## Why

当前联机测试中，门、按钮、触发器和可交互物品的状态不能稳定传播；共享资源库存菜单只修改了持久化设置，运行中的服务器没有立即请求客户端重新上报资源，且新加入玩家的资源基线可能导致后续增量错误。

## What Changes

- 为常见门输出增加 `FIRE` 同步，并补齐门、移动门实体的跟踪。
- 让运行中的共享资源设置立即生效，并向已连接客户端请求资源快照。
- 将共享资源广播后的权威值写回所有接收者的资源基线，避免第二次资源变化被错误计算。
- 修复可交互输出回调中的方向命名错误。

## Non-goals

- 不改变独立资源库存模式的行为。
- 不引入新的网络协议或第三方依赖。
