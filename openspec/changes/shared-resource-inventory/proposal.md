# Proposal

## Why

当前 addon 只在本地记录弹药和树脂，服务器无法把资源变化传给其他玩家；同一资源可能被重复拾取，库存也无法按服务器规则统一。需要补上资源快照同步，并让主机选择玩家独立库存或全队共享库存。

## What Changes

- 增加弹药（手枪弹匣、冲锋枪弹匣、霰弹）和树脂的资源快照协议。
- 增加服务器选项“共享资源库存”；关闭时保持玩家独立库存，开启时由服务器维护共享池并回写到所有已初始化玩家。
- 防止共享库存的回写命令再次被当作玩家增量，避免资源同步回声和重复计数。
- 增加协议、共享池和设置回归测试。

## Capabilities

### New Capabilities

- `resource-inventory-sync`：资源快照、独立库存与共享库存行为。

### Modified Capabilities

- 无。

## Impact

影响 addon `kcom_interval.lua`、玩家事件资源统计、AlyxGamemode 协议处理、服务器设置和 WinForms 选项菜单。不改变门、按钮、物品位置同步协议；不包含跨地图持久化共享池。
