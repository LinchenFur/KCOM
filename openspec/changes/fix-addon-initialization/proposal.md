# Proposal

## Why

按既有计划继续修复原项目 Issue #2 的初始化/地图识别问题。当前认证可能先于 VConsole 连接完成，首次换图命令会丢失；脚本仅以实体存在为成功依据；服务端在实际地图回报到达前就宣告完成。

## What Changes

- 保证控制台连接先于认证；连接失败时明确提示客户端未启动，可停止后重试。
- 初始化探测以脚本完成标记为依据，失败时节流重试并提示。
- INIT/IENT 按单个玩家的初始化阶段去重；延迟任务在断线或新初始化后失效。
- 有效 MAPN 且 API 匹配后才报告成功，更新该玩家地图；拒绝缺字段、非法地图名和错误版本。
- 统一校验启动和换图地图名，避免错误输入变成控制台命令。
- 增加回归测试；多人实机测试明确待完成。

## Capabilities

### New Capabilities

- `addon-initialization`：有序、可重试、可确认的 addon 初始化及地图输入。

### Modified Capabilities

- 无。

## Impact

客户端连接顺序、VConsole 生命周期、AlyxGamemode、游戏就绪脚本和地图输入处理。不增加依赖，不扩展多语言功能，不改变门及物品同步，不下载或替换地图。
