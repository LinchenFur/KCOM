# Design

## Decisions

- 保留已有 KRDY/INIT/IENT/MAPN 协议。客户端先连接 VConsole 再启动 WebSocket；连接失败释放客户端实例，不发送认证，日志指出如何重试。WebSocket 断线/手动停止先取消游戏探测。
- 每个 Player 保存初始化代次和阶段；KRDY 重置，INIT/IENT 只处理一次。延迟 2.5 秒的任务检查玩家对象、代次、阶段和连接可用性；异常不会成为未处理线程异常。
- 新游戏脚本使用 KCOM_INITIALIZED 标记，只有实体扫描完成才设为 true 并输出 MAPN。探测读取 logic_script 的私有脚本作用域，实体存在但脚本失败不得停止重试；10 秒节流，重试通过固定 KERR 报文报告失败。
- MAPN 字段、地图名及 API 版本均有效且属于当前初始化阶段时才报告成功。失败不修改当前地图，也不播放成功音。重复报告不重复宣告成功。
- 地图名使用统一的 ASCII 字母/数字/下划线/连字符以及目录分隔符白名单，去除首尾空白；拒绝空名、扩展名、反斜杠、点路径、分号、引号及控制符。共享函数用于服务器启动/换图和客户端认证；错误以日志返回。
- 测试使用已有控制台测试工程，增加客户端的无窗口 UI/空 Lua 回调桩，实际运行 WebSocket 和 TCP 验证顺序；Lua 用最小游戏 API 桩复现“实体存在但脚本未初始化”。不将这些测试称为真实多人或地图验证。

## Non-Goals

不开发语言选择器，不修复所有地图，不重构服务器线程模型，不自动下载 Workshop，不宣称修复全部卡死。
